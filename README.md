# Computational Biophysics Workshop Website - V3.5.0

This release adds **Training Day 7 (19 August 2026)** molecular dynamics resources to the participant-facing materials library and workshop gallery.

Training Day 7 is selected by default in **Materials, Program, and Workshop Gallery** so participants immediately see the latest session.

## Training Day 7 - Molecular Dynamics

New participant resources:

- Shared Training Day 7 Google Drive folder
- **Molecular Dynamics Simulation** PDF
- **From Docking to Dynamics: Preparing Protein-Ligand Systems with CHARMM-GUI for GROMACS Simulations** by Donia Gamal Youssef Soliman
- Direct CHARMM-GUI and GROMACS website links
- Two Google Colab notebooks
- Original practical RAR archive with GROMACS MDP files, PDB, commands/scripts, images, and demonstration videos
- 12 unique optimized Training Day 7 workshop photographs
- New Training Day 7 gallery tab
- Training Day 7 marked as completed / materials available
- New `website` material type for participant-friendly external tool links

## Deployment

Upload the contents of this folder to the GitHub Pages repository root, preserving the `assets/` directory structure. Replace `index.html` and the new versioned JavaScript files when prompted.
