# V3.4.0 Update Instructions

This package updates the existing Computational Biophysics Workshop website with Training Day 6 protein-protein docking materials and photographs.

1. Extract the ZIP.
2. Upload everything inside the extracted folder directly to your GitHub Pages repository root.
3. Preserve all `assets/...` paths exactly.
4. Replace `index.html` when prompted.
5. Wait for GitHub Pages to redeploy, then hard-refresh the website.

Training Day 6 will open by default in Materials, Program, and the workshop photo gallery.
