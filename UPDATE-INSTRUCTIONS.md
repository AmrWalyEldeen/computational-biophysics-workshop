# V3.5.0 Update Instructions

This package updates the existing Computational Biophysics Workshop website with Training Day 7 molecular dynamics materials, practical links, and photographs.

1. Extract the ZIP.
2. Upload everything inside the extracted folder directly to your GitHub Pages repository root.
3. Preserve all `assets/...` paths exactly.
4. Replace `index.html` when prompted.
5. Upload the new `assets/js/*.v3.5.0.js` files and all new Day 7 assets.
6. Wait for GitHub Pages to redeploy, then hard-refresh the website.

Training Day 7 will open by default in Materials, Program, and the workshop photo gallery.
