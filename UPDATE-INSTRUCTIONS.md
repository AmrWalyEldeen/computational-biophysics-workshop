# Update Existing GitHub Website to V3.1.1

1. Extract the update ZIP file.
2. Open the GitHub repository.
3. Select **Add file > Upload files**.
4. Upload everything inside the extracted update folder.
5. Allow GitHub to replace existing files and add the new folders.
6. Commit with: `Add Training Day 1 materials and gallery`
7. Wait 1-3 minutes for GitHub Pages.
8. Force-refresh the website: `Ctrl + F5` on Windows or `Cmd + Shift + R` on macOS.

Important new folders and files:

```text
assets/materials/day-1/
assets/training-day-1/
assets/materials/thumbnails/introduction-linux-mahmoud-noamaan.webp
assets/materials/thumbnails/introduction-structural-biology-abdo-elfiky.webp
```
